<h2 class="section-title">Course Description</h2>
<p>An advanced course on database systems covering the design, implementation, and use of both relational and non-relational database systems. Topics include the relational data model, SQL, physical data organization, indexing, query processing and optimization, transaction management, concurrency control, and modern database paradigms including column stores, key-value stores, document databases, distributed databases, and vector databases.</p>
